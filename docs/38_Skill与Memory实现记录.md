# Skill 与 Memory 实现记录

日期：2026-11-04。实现位置：`apps/api/app/skills.py`、`memory.py`，迁移 `0005_memory_skills`。目标设计见10章，本章仅记录已运行的子集。

## Skill

四类 Agent 各有内置 published 模板。发现仅返回元数据；选中后按需加载正文、校验内容哈希和 Agent 边界，缓存按 owner/版本/内容哈希隔离。每次加载私有模板重新检查发布状态，退役后不因缓存继续使用。

步骤来自固定白名单：证据、质量、全窗覆盖、练习约束、反馈与生成能力查询。模板无法上传/执行代码、访问额外网络或增加 Agent 工具权限。Knowledge 的选中正文会进入真实模型适配器提示词；测评/规划的约束仍由确定性代码执行，模板不替换评分算法。

私有版本经历 candidate → reviewed → published → retired，也支持 rejected。审核是本人本地工程审核，Critic 为静态边界检查，不是独立 LLM、教师认证或复杂自适应算法。完成任务可提取候选固定步骤类型，但不复制私有轨迹正文，也不自动发布。

## Memory

默认关闭。只有用户显式启用后才记录跨会话元数据和确认偏好；关闭后规划不消费已有偏好。

- L1：偏好确认事件、任务完成的类型/结果状态/产物ID；不存完整问题正文或音频。
- L2：用户确认的 goal 和 minutes，包含来源事件与 revision；删除字段写 tombstone。
- L3：仅从 confirmed facts 生成确定性摘要，附来源ID和 user_confirmed 标记；不推测疾病或演唱水平。

偏好修改/授权使用 revision 冲突检查，过期请求返回409。当前用户输入优先于记忆；只有省略的目标/时长才补充默认值。

业务任务完成在同一 fenced finish 事务内追加去重事件并创建 memory 内部任务及 outbox。压缩使用输入 revision 检查；用户修改、删除或撤权后，旧任务返回 superseded。压缩写入也放在 worker 的受令牌/版本/租约保护的完成事务中，取消或旧 worker 不能发布压缩副作用。memory 类型不再触发新 memory 任务，避免递归。它不是公开可创建的业务任务类型。

清除删除 Memory 表内事件/事实、清空摘要并关闭。**源报告、计划、检查点和既有内部任务不随此操作删除**，界面有范围提示；不能宣传为全账户数据删除。已删除偏好的旧 source event 仍可能存在于历史事件中，单字段删除代表“不再使用该事实”，完全清除请用清除全部。

## 测试

自动测试覆盖发现不加载正文、哈希/跨 Agent 拒绝、候选发布顺序、owner 隔离、退役缓存失效、授权默认关闭、revision409、来源追溯、删除不复活、关闭不消费；异步测试覆盖完成事件去重、仅一次压缩任务、无递归、旧 revision 失效、取消后清除不会写回。桌面与手机浏览器测试覆盖偏好保存/清除和模板审核发布退役。

未实现完整的长期事件保留/提取模型、可撤销全资源账本、滑动多轮对话记忆与真实 tokenizer 节省评测。本工程不宣称达到原图中50～70%的 Token 节省。
