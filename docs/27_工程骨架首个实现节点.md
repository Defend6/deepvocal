# 工程骨架首个实现节点

本文件记录从项目书进入开发后的第一个可验证节点。它不代表四类 Agent 已经完成，也不代表真实模型、GraphRAG、音频算法或歌声生成服务已经接入。

## 已建立内容

- 本地根目录：`D:\deepvocal`
- 后端：FastAPI 最小入口、健康检查、结构化规则路由、Agent capability 查询
- Agent 边界：Knowledge、Assessment、Planning、Singing 四类名称固定；Supervisor 只负责路由决策
- 前端：React + TypeScript 工作台，按目标图建立四类 Agent 入口和 Mock 状态
- 基础设施：PostgreSQL、Redis、RustFS（S3 兼容）、Neo4j、Milvus 与 etcd 的 Docker Compose
- 测试：路由正例、生成确认门控、低置信度澄清

## 运行边界

- `DEEPVOCAL_MODE=mock` 时只允许本地规则和占位响应。
- `SINGING_ENABLED=false` 时，歌声生成只能返回能力禁用状态，不能伪造生成任务。
- 录音、知识库和用户身份尚未接入业务数据库；本节点不创建真实用户数据。
- 数据集目录沿用项目书基线，后续数据分支完成审核后再生成索引版本。
