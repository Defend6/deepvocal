日期：2026-11-04。

## 已完成

1. `python -m app.knowledge.cli prepare` 生成研究 bundle 和逐来源许可处理清单，位于 datasets/working。文本/元数据变更有 SHA-256 指纹；加载时重新检查语言、许可分区、审核状态和指纹。
2. `python -m app.knowledge.cli ingest` 分批调用 embedding，幂等写入 Milvus 与 Neo4j；两者完成后原子发布 active manifest。无 Key 时不发请求，不写假 embedding。
3. 问答使用中文二字词召回、Milvus cosine、Neo4j 实体提及召回、RRF 合并、reranker 和 LLM；返回证据原文、标题、来源、哈希、许可和审核状态。缺证据、相关性低、错误引用编号和健康问题分别拒答。
4. 索引身份包含语料内容、模式、API base 和 embedding 模型；模型或语料变更需重建。研究和生产模式不共享启用条件。

## API Key 接入

`.env.example` 已提供一组可配置的 OpenAI-compatible chat/embeddings + rerank 默认值。研究链路本地基础设施已具备，补 `MODEL_API_KEY` 后可执行 ingest；问答在未发现索引时也会触发导入。默认供应商和模型是工程配置，未使用真实 Key 验证其账户权限、服务可用性、费用或模型质量；如账户不提供这些模型，需替换模型名或 API base。不会把模拟 HTTP 测试写成供应商真实调用成功。

无 Key 的问答明确返回 disabled 和引用资料预览，预览不是模型答案。研究资料不是教师审核知识库。

## 中文语料与许可问题的处理结果

当前选入 12 篇项目原创中文工程知识草稿，覆盖测量概念、录音、练习边界、任务参考等；仅当前项目研究使用，全部标 NEEDS_REVIEW，专家审核仍为 false。资料用于验证流程，不声称替代专业教材。

已有 5 个原始来源和 11 个中文维基条目完成自动分区报告：2 项因 NC/SA 默认公开生产策略阻断，14 项待语言、归属和专业内容复核。BLOCKED 表示本项目默认公开生产策略不接收，不是宣称该许可普遍禁止研究使用。CC-BY-SA 中文条目需要完整归属和相同方式共享等条件，不混入默认生产库。英文来源不因中文标题而算中文正文，当前不会自动翻译后授予不存在的许可。

自动工具不能替代权利人的授权或声乐专家签字。可执行解决路径为：保留来源及许可分区；不合条件的内容隔离；项目原创草稿先在研究模式运行；后续经明确授权/归属核验和内容复核的条目才切 APPROVED。production 同时要求允许的许可证、专家审核和逐条 production_enabled，不能只修改总开关绕过。

## 验证与边界

真实 Neo4j 与 Milvus 通过幂等写入、实体查询、向量查询与模型变更拒绝测试；使用独立测试 collection 与明确的合成向量，结束删除，未冒充真实 embedding。Provider 使用 mock HTTP 验证请求字段、批次顺序、响应维度和密钥脱敏；引用越界拒绝测试通过。Milvus 2.4 的 Python 客户端需要 setuptools<81，已约束依赖。

当前引用检查证明编号和出处存在，不能证明生成文本的每句话被语义蕴含；真实问答仍需基于保留评测集评测事实一致性、拒答和中文覆盖。生产专家审核、真实模型质量评测仍未完成。
