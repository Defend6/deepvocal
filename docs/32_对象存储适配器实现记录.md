# 对象存储适配器实现记录

日期：2026-11-04  
分支：`feature/platform-skeleton`

## 本次完成

- 增加 S3 兼容对象存储适配器，兼容本地 RustFS 和后续其他 S3 服务。
- 增加 bucket 初始化、预签名 PUT、对象 HEAD、对象删除操作。
- 预签名上传强制要求 `audio/*` 内容类型，启用 AES256 服务端加密，并限制签名有效期为 60 到 3600 秒。
- 对象 key 必须是相对路径，拒绝空 key、绝对路径、路径穿越和超长 key。
- SDK 延迟导入，单元测试可以使用 fake client，不依赖真实存储网络。

## 安全边界

适配器不负责判断用户是否拥有对象。owner、用途、数据库资产行、大小限制、哈希核验和上传完成事务必须由上层 upload service 与 PostgreSQL 一起完成。当前没有直接暴露上传 API，因为鉴权和可信 owner 上下文尚未实现；这避免出现未授权预签名接口。

## 下一步

1. 先完成本地开发 JWT/OIDC owner 上下文和用户隔离。
2. 在同一事务中创建 `audio_assets` pending 行和 upload ticket。
3. 完成对象后通过 HEAD 核验版本、大小、Content-Type 和服务端计算哈希，再将资产置为 ready。
4. 接入任务提交、outbox 和 worker；上传完成不应自动触发测评。
