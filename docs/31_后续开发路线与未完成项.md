## 已确认的范围选择

- 本地测试身份已实现 owner 隔离；OIDC 只留配置，尚无真实 Bearer/JWKS 校验。不得部署公网。
- 仅预签名 URL 和浏览器 PUT，pending 不转 ready；完成回调/对象完成校验/过期清理没有偷偷启用。
- 歌声生成始终禁用，只提供能力入口和替换位置；真实生成不是本轮交付条件。
- 当前功能分支提交/推送，不自动合并、不公开仓库。

## 按合理顺序继续开发的缺口

1. **真实模型联调**：提供账户 Key，核实 chat/embedding/reranker 实际支持；重新生成索引；执行真实问答基准、引用语义一致性、失败与限流测试。现有适配器测试不证明提供商账户可用。调用量有输入与输出限制，但货币预算/预占/结算尚未实现；D-007 的正式付费启用条件尚未全部满足。
2. **中文知识质量**：研究种子12条为原创工程草稿；既有35文档/166切块、中文抓取资料与限制性许可来源不自动进入生产。补足声乐专家逐条审核、可追溯许可/署名、代表性问答集与独立测试集。规则审查无法替代版权授权或专业内容审查。
3. **录音端到端**：如用户以后改变“仅预签名”选择，再开发完成校验、重复/过期/重传语义、异步探测、ready 转换和回收。不要手工把真实未知资产改成 ready。
4. **声学可靠性**：解码目前在线程执行，尚非独立受限进程；需进程隔离/资源限制、中文清唱基准、更多错例分析、时间轴自动对齐与教师评分校准。现有基准不能证明全曲教学准确性。
5. **Skill/Memory 深化**：当前是固定声明式步骤和用户确认偏好。自主技能归纳、LLM Critic、多轮滑动窗口、事件长期保留、全资源删除 ledger、实际 Token 对照评测尚未完成。
6. **生产工程**：OIDC、角色/配额/速率限制、审计/指标/告警、完整漏洞扫描、迁移回滚演练、对象和图/向量索引备份。当前备份恢复仅覆盖 PostgreSQL，真实生产高可用未验证。
